01 / The method

Learning without a map

First, the agent learns a world it can dream inside.

Each 64-by-64 observation becomes a compact latent state. A recurrent state-space model combines that visual evidence with memory and the previous action, then learns to predict what follows.

During training, Dreamer starts from states sampled from replay and rolls its learned dynamics forward for fifteen steps without receiving new game pixels. Predicted rewards and continuation probabilities train a policy and value function inside those imagined trajectories. During evaluation, the actor acts directly from the current posterior state. It does not run an online planning search before every move.

Exact parameter accounting

Inside the 10.49-million-parameter agent.

The model is not one monolithic network. It is a jointly optimized world model, actor, and critic. The world model contains 8,849,347 parameters; the behavior system contributes the remaining 1,642,756.

Maps latent features to probabilities over five Mario controls. During training, gradients favor actions with high normalized lambda-returns across imagined 15-step trajectories while retaining stochastic exploration.

Distributional value model

853,503

Estimates the long-term return of each imagined latent state as a 255-bin symlog two-hot distribution. Those values bootstrap lambda-return targets and supply the actor's learning signal without querying the emulator inside imagination.

02 / The engineering record

Implementation as investigation

The failures were part of the result.

V1, our custom PyTorch implementation, exposed how small semantic errors can produce plausible losses and unusable behavior: replay windows crossed resets, temporal targets drifted out of alignment, and deterministic argmax evaluation misrepresented a categorical policy.

For V2, we built a Mario environment adapter that emits Dreamer's image, reward, is_first, is_last, and is_terminal fields; maps NOOP, right, right+A, right+B, and right+A+B into discrete controls; repeats each action for four emulator frames; and supplies 64-by-64 RGB observations. We also implemented checkpoint resolution, frozen-policy evaluation, episode-level metrics, raw-frame video capture, and a synchronized collector that places decoded open-loop latent predictions beside their real emulator outcomes. The resulting 10,492,103-parameter checkpoint was trained for 98,420 action steps and evaluated with no further learning.

The next question

Can one learned world transfer to the next?

The current agent learned one level from one training seed. The research extension is to test whether shared latent dynamics can support fast adaptation across related platforming levels without environment-specific obstacle rules.
